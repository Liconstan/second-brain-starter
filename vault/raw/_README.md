# raw/

The originals, kept forever: `raw/granola/` (or the name of your notes tool), `raw/gmail/`, `raw/slack/`, `raw/docs/`, `raw/memo-events/`. **Never edit, overwrite or delete a file here.** A new version of a source gets a new file with its date in the name. `raw/private/` is for exports that must not go to GitHub; git ignores it.
