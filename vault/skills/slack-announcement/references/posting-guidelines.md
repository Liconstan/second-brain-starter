# Posting guidelines (condensed)

Source: the community's own guidelines, [POSTING_GUIDELINES_LINK]. If that is unfilled, these defaults apply. When the real guidelines arrive, rewrite this file from them and keep the same headings.

## Routing rules

- Jobs, fellowships, incubators, competitions, board roles → [SLACK_CHANNEL_FOR_JOBS]
- Funding applications → [SLACK_CHANNEL_FOR_FUNDING]
- Other unpaid opportunities → the help-requests channel in `channel-map.md`

## Basic principles

- Must relate to what the community is about: [COMMUNITY_SCOPE]. If the link is indirect, say how it connects.
- Include essentials so people can assess quickly.
- Concise and skimmable. Bullets for key details. Link out for the rest.
- Make next steps clear: how to apply or get in touch.

## Minimum requirements for job-type posts

- Role or title, linked to the official posting
- Organization, linked to its website
- Location. Communities usually prefer remote or major hubs. Say which.
- Compensation, if it's notably above or below market or otherwise unexpected

## Optional but encouraged

- Most restrictive requirement (e.g. PhD, 7 years experience)
- The poster's connection to the organization
- Employment type (full time, part time, contract, internship)
- Length of engagement
- Deadline or timeline
- Pay range, or state that it isn't known. Especially if not visible on the linked page.

## Formatting rules

- One link preview per post. Slack previews every link by default. Keep the main link last so that's the one that previews, and keep other links minimal.
- One message only. Never split a post.

## Applying this to funding posts

Guidelines are often written for jobs, but the same spirit applies. For funding, the equivalent minimums are:
- Fund name and who runs it
- Who can apply (individuals, organizations, both)
- Roughly how much (range or cap)
- What it covers or excludes (e.g. no PI salary)
- Deadline
- Application link
