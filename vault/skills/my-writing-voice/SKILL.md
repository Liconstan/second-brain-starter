The fastest way: after the nightly sync has saved some sent mail and chat messages to `writing/`, send an agent this memo: "Read writing/ and me/writing-voice.md, and propose my writing voice skill. Show me five real examples for each claim."

## Process

1. Read the people file of the reader: "How [YOUR_FIRST_NAME] writes to them" has the channel, the tone, and the latest real message.
2. Draft. Then cut a third.
3. Compare with the reference examples above, line by line.

## Learning loop

When [YOUR_FIRST_NAME] sends a different version of a draft, save that version, word for word, in the people file of the reader and in `writing/`, and propose a change to this skill in a memo when the same edit comes a second time.
